## 二、SpaceEngine 美感来源拆解

SpaceEngine 是 C++ 桌面软件（全 GPU 着色器管线 + 程序化生成），浏览器无法 100% 复刻，但核心手段在 three.js 中均有对应 Web 实现，"神似"完全可行。

### 1. 光照与大气（氛围感的灵魂）
星球边缘蓝紫色光晕是**大气散射实时计算**：光线穿过大气被空气分子散射（瑞利散射偏蓝、米氏散射偏白），边缘发蓝、晨昏线泛红。当前 Catalog3D 的菲涅尔大气壳只是假象，升级为散射模型后质变。

### 2. 程序化表面（"无限精度"的真相）
星球表面是**噪声函数实时生成**：多层分形噪声（fbm / Perlin / Worley）叠加出大陆、山脉、陨石坑、沙丘，随机种子决定每颗星球唯一地貌。近距离细节不减，即"高精度建模"错觉来源。

### 3. 后处理（电影感的临门一脚）
Bloom（亮部泛光）、ACES 色调映射（胶片级色彩）、暗角、胶片颗粒、微色差——画面"像电影"九成靠这层。

### 4. 体积元素
体积云（ray marching）、星云尘埃、恒星体积光——深空里飘着"有厚度"的东西。

## 三、Web 端复刻路线（three.js 对应方案）

| SpaceEngine 手段 | three.js 实现 | 难度 | 见效 |
|---|---|---|---|
| 后处理全套 | @react-three/postprocessing（Bloom / Vignette / ToneMapping / Noise） | ★☆ | 立刻 |
| 大气散射 | 瑞利/米氏散射 shader（单次散射近似） | ★★★ | 大 |
| 程序化星球表面 | ShaderMaterial + fbm 噪声实时生成 | ★★ | 大（特写时） |
| 星云背景 | 多层透明 sprite + 噪声贴图 | ★★ | 中 |
| 体积云 | ray marching 体积云 | ★★★★ | 大但性能紧 |
| LOD 细节层次 | THREE.LOD（远处低模，近处细分） | ★★ | 特写时必要 |

## 四、星表页落地推进顺序

1. **第 1 步（性价比最高）：后处理升级**——Canvas 加 Bloom + Vignette + ACES 色调映射 + 胶片颗粒，零模型改动，整页从"干净的 3D 展示"变"有电影感的宇宙"
2. **第 2 步：大气散射升级**——主角 4 颗的菲涅尔壳换散射模型，边缘蓝晕 + 晨昏线渐变（"SpaceEngine 感"最集中的一点）
3. **第 3 步：程序化星球表面**——shader 生成地表（替代/叠加现有纹理），颜色倾向 + 噪声种子决定唯一地貌，点击特写时细节依然锐利
4. **第 4 步（氛围收尾）：星云背景 + 体积光**——深空背景加 2-3 片极淡星云，恒星方向加体积光柱
