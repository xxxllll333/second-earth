## 二、全局交互约定

### 2.1 导航系统
- 顶部四圆点路径指示器：星表→星系→光谱→演化。当前层亮金色，已经过的层灰实心，可点击回跳。
- 穿透方向语义：向微观层进入 = 原视图放大淡出（zoom-in）+ 点击处金色粒子环扩散；返回 = 缩小退回（zoom-out）。过渡时长 450ms，缓动 ease。
- 搜索框：输入即联想（datalist），回车跳转目标星系并选中该行星；未命中 toast 提示候选名。

### 2.2 视觉编码（数据即画面，不美化）
- 光点大小 = 行星半径（√R 映射，2.8–10px）；颜色 = 平衡温度（120K 红 → 2800K 蓝，分段线性插值）。
- 被否决行星：统一灰 #9AA0AE + 划线标记；点击弹出否决档案模态。
- 主角（K2-18b、WD 1856b）：微光晕脉动（3.4s 呼吸），吸引注意但不强制。
- 团队配色：团队A 暖色系、团队B 冷色系（光谱画廊）。

### 2.3 反馈与容错
- Toast：底部居中，2.6s 自动消失；用于收藏、筛选越界、无光谱数据等轻反馈。
- 模态：Esc / 点击遮罩 / ✕ 三种关闭方式；打开时背景模糊 6px。
- 空状态：我的星表为空时给出引导文案；搜索无结果给出候选提示。
- LocalStorage 不可用（如部分内嵌预览环境）：自动降级内存存储，并在收藏时 toast 告知。

### 2.4 移动端（<920px）
- 信息面板改为底部抽屉（max-height 38vh）；光谱卡宽 82vw；星图支持单指平移 + 双指捏合。

## 三、分层交互细则

### 3.1 层级一 · 星表
| 手势/控件 | 行为 | 参数 |
|---|---|---|
| 滚轮 | 以光标为中心缩放 | k∈[1,9]，factor=e^(−Δy·0.0016) |
| 拖拽 | 平移视野 | k=1 时锁定边界（不可拖出画布） |
| 双指 | 捏合缩放（触屏） | 以双指中点为锚 |
| 双击 | 平滑复位 | 320ms，cubic-out |
| 悬停 | 浮动卡 + 右侧档案 | 触屏不触发浮动卡 |
| 点击光点 | 粒子环 → 穿透星系 | 环扩散 700ms；240ms 后切视图 |
| 筛选按钮 | 未命中淡出 | opacity 0.5s；不删除节点（诚实呈现全量） |
| 缩放 >1.7× | 渐显名称标签 | 主角 >1.05× 即渐显 |

边界：拖拽后释放 50ms 内的 click 被抑制（防误触穿透）；筛选后未命中光点 pointer-events 关闭。

### 3.2 层级二 · 星系
- 点击行星 = 选中（金色虚线环）；Ctrl/⌘+点击 = 加入/移出对比集（上限 2 个对比 + 1 个选中）。
- 雷达图六轴：半径/质量/平衡温度/辐射通量/轨道周期/大气概率；质量与周期取 log 归一；缺失质量按 0.06 占位并标注"待测定"。
- 被否决行星：点击仍可选中并叠加弹出否决档案（证据/结论/科学意义/数据来源）。
- 底部操作栏：「查看光谱档案」对无光谱行星禁用（置灰 + title 提示）；「收藏此星」为切换式（☆/★）。

### 3.3 层级三 · 光谱画廊（核心叙事）
- 散点为"真实观测值"（模型A + 种子化噪声），任何模式下不移动、不平滑。
- 团队A/团队B 两张卡共享同一组散点 —— 差异只在拟合线，这是争议的视觉前提。
- 置信度滑块（仅 NIRISS 卡，因其覆盖 1.1–1.5μm 争议区）：
  - 值 0–100；拟合线 = lerp(模型A, 模型B, t)；散点恒定。
  - 结论横幅三态：<35 含DMS生命模型（青）；35–65 证据不足（金）；>65 非生物模型（橙）。
  - t<55 时显示「DMS 特征区?」半透明青带。
- 误差棒：±1σ，rgba(210,220,235,.38)，1px；开关带 toast 解释其科学含义。
- 全屏模态：散点/拟合/误差棒三层独立开关（分离显示）；NIRSpec/MIRI 卡不显示滑块并解释原因（波段不覆盖争议区）。

### 3.4 层级四 · 恒星生命卷轴
- 时间轴域 [0,12] 亿年；拖拽手柄即时 setT；滚轮以光标为锚缩放域（最小跨度 0.6 亿年）；双击复位。
- 恒星视觉：主序 #FFD97A → 红巨星 #FF4A30（半径 24→126px，pow 0.72 缓动）→ 白矮星 #DCE9FF（6px）；光晕透明度随 log(L)。
- 吞没规则：恒星半径(R☉) ≥ 轨道距离(AU)×215 时行星标记为吞没（节点淡出、曲线终止 ✕、芯片划线）。
- 宜居带环：半径 ∝ √L，随光度外移；超出舞台自动隐藏。
- 追踪面板：锁定芯片切换；对数温度轴 80–3000K；液态水窗口 230–320K 绿色带；游标虚线随 t 跳动。

### 3.5 我的星表
- 排序：最近/名称/半径；导出：JSON（归档）与 CSV（Excel）；「前往」穿透至该星系。
- 顶栏徽标实时计数；空态引导回星表。

## 四、生产环境移植要点（React）

| 原型实现 | 生产组件（提案 4.3 组件树） | 说明 |
|---|---|---|
| bindMapGestures | StarMap + d3-zoom | 用 d3.zoom 替换手写变换，保留 k∈[1,9] 与边界钳制 |
| renderRadar | RadarChart | 六轴归一函数 radarNorm 直接复用 |
| 光谱模型/绘制 | SpectrumCard / SpectrumDetail | 模型A/B 与 lerp 拟合逻辑直接复用；渲染换 D3 |
| 时间轴 | TimelineAxis | 域缩放状态入 evolutionStore |
| FavStore | collectionStore + LocalStorage | 接口不变（list/has/add/remove） |
| showView/warp | Framer Motion 路由过渡 | 保留"放大进入/缩小退回"语义 |

性能红线（提案 4.7）：星图 500+ 点 ≥30fps（Canvas 背景层）、光谱切换 <100ms、时间轴拖动 60fps。
