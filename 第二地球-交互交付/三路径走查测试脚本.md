# 「第二地球」三路径走查测试脚本

前端-交互 · W4 任务 4.9 交付物 · v1.0 · 2026-08-25

> 用法：每周四联调后，按本脚本从头到尾走一遍。每步在"实际"列打 ✅/❌；❌ 需记录复现步骤并开 issue。
> 环境：Chrome 桌面端（主测）、Safari/iOS 与 Android（抽测）。原型地址：`index.html` 或公网链接。
> 快捷方式：原型内置「▶ 引导演示」可自动执行路径一（兼作回归冒烟）。

## 路径一：发现 K2-18b 争议（核心叙事，必须 100% 通过）

| # | 操作 | 预期结果 | 实际 |
|---|---|---|---|
| 1 | 打开应用，进入星表 | 星空背景闪烁；状态栏显示"当前显示 23 颗…"；无控制台报错 | |
| 2 | 滚轮放大星图至 2× 以上 | 光点标签渐显；缩放以光标为中心 | |
| 3 | 点击筛选「有光谱数据」 | 无光谱光点淡出（不消失）；状态栏计数变为 14 | |
| 4 | 悬停 K2-18b 光点 | 浮动卡显示：2.37 R⊕ / 272K / 124 光年 | |
| 5 | 点击 K2-18b | 金色粒子环扩散 → 穿透进入 K2-18 星系视图；面包屑"星系"点亮 | |
| 6 | 点击「查看光谱档案 →」 | 进入光谱画廊；4 张卡片横向排列 | |
| 7 | 左右滑动画廊 | 流畅横滑；团队A 暖色、团队B 冷色一目了然 | |
| 8 | 点击「NIRISS SOSS · 团队A」卡片 | 全屏放大；散点、拟合线、坐标轴清晰 | |
| 9 | 打开「误差棒」开关 | 每个散点长出 ±1σ 细银线；toast 解释含义 | |
| 10 | 置信度滑块拉到 0 | 拟合线穿过 DMS 特征区；横幅显示"含 DMS 生物标志物模型" | |
| 11 | 滑块拉到 100 | **散点不动**，仅拟合线变化；横幅切换为"非生物模型" | |
| 12 | 关闭散点层、再打开 | 图层可分离显示，无残留 | |
| 13 | 按 Esc 返回画廊，再返回星表 | 缩小退回动画；筛选状态保留 | |

## 路径三：看一颗恒星的生死

| # | 操作 | 预期结果 | 实际 |
|---|---|---|---|
| 1 | 任意视图点击面包屑「演化」 | 进入生命卷轴；默认 t=4.6 亿年，黄色主序星 | |

| 7 | 双击时间轴 | 复位 [0,12] 全域 | |
| 8 | 拖回 4.6 | 一切恢复"现在"状态；WD 1856b 标记点可见 | |
