## 打开方式

双击 `index.html` 用 Chrome 打开即可（无需服务器、无需网络）。

快速体验建议顺序：

1. 星表页点「▶ 引导演示」——自动走一遍 K2-18b 争议路径（约 35 秒，点击可跳过）；
2. 自己走路径二：筛选「潜在宜居」→ TRAPPIST-1e → Ctrl/⌘+点击 f、g 对比 → 点灰色 1d 看否决档案；
3. 走路径三：面包屑「演化」→ 拖时间轴到 110 亿年，看红巨星吞没水星金星；
4. 收藏几颗星 → 右上角 ★ 打开「我的星表」→ 导出 CSV。

用于交互演示；生产环境由后端 API 提供全量 5000+ 数据与 MAST 原始光谱。
